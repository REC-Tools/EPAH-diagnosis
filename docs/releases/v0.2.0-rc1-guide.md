# v0.2.0-rc1 | Software source-only pre-release

Questa è una **pre-release del codice**, non una diagnosi
territoriale approvata o una pubblicazione dei risultati.

Tag GitHub previsto: `v0.2.0-rc1`.
Versione Python: `0.2.0rc1` (compatibile PEP 440).
Sono inclusi i sorgenti GitHub e un piccolo JSON di attestazione
della natura *source-only*; **nessun archivio con i 27 PDF**, il rapporto
tecnico o i CSV locali viene caricato nella release.

## Processo (senza approvazioni simulate)

1. Revisionare questa PR di release, i lockfile e il workflow.
2. Merge su `main` (CI completa verde obbligatoria).
3. Al push del manifest `docs/releases/v0.2.0-rc1.json` su `main`,
   GitHub Actions riesegue i test e pubblica automaticamente la
   pre-release `v0.2.0-rc1` con `--prerelease --latest=false`.
   Il medesimo workflow si può avviare manualmente in *Actions*
   solo da `main`. Non modifica una release o un tag già esistente.
4. Verificare GitHub > Releases > `v0.2.0-rc1` e la dicitura
   "Pre-release"; la release contiene solo codice e attestazione.
5. Per il pacchetto territoriale **privato** generare da input
   validati i cinque componenti con `epah report/sheets/analysis/dashboard/review-pack v0.2`,
   poi `epah audit v0.2` su una cartella nuova.

L'assenza di originali e audit sul runner GitHub è intenzionale:
la CI usa dati sintetici e non distribuisce PDF/mappe in una release
pubblica di codice.

## Gate non soddisfatti per una vera release territoriale

- Confronto scientifico tra fonti, anni e definizioni di nove indicatori.
- Revisioni e licenze per ciascuna fonte.
- Verifica visiva delle 27 schede e di tutte le pagine del PDF.
- Controllo editoriale del branding e delle diciture EPAH.
- Approvazione dell'Unione Montana e autorizzazione alla diffusione.
- La matrice canonica 243 osservazioni e le nove approvazioni
  metodologiche restano separate dal pilota accettato tecnicamente.
- CIT in quarantena escluso; non deve bloccare il rilascio del software.

**La spunta verde dei test non modifica alcuno di questi stati.**
