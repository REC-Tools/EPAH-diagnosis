# Integrated municipality diagnostic profile

The municipality profile now combines the validated indicators generated by
the diagnosis pipelines without collapsing them into a single score.

For each of the 27 municipalities it contains:

## Energy-poverty vulnerability proxies
- population aged 65 and over (%)
- low-income taxpayer proxy (%)
- residential buildings built before 1981 (%)

## Climate and territorial exposure
- heating degree days
- mean municipal altitude
- official SNAI A-F class

## Access to essential services
- road minutes to nearest DEA I/II municipality
- road minutes to nearest complete upper-secondary education pole
- road minutes to nearest validated active passenger rail gateway

The profile deliberately does not define a synthetic energy-poverty or
isolation score. Each dimension remains inspectable and traceable to its
source.

## Build sequence

After all indicator finalizers have completed successfully:

```
python scripts/build_municipality_profile.py
python scripts/build_municipality_geojson.py
python scripts/generate_diagnostic_maps.py
```

The map generator produces eight individual diagnostic maps. SNAI class is
stored in the profile and GeoJSON as a categorical field but is not converted
to an arbitrary numeric choropleth score.
